# 03 函数

[返回学习入口](../README.md) · [配套练习](../06-exercises/README.md)

## 学习目标

能声明、定义和调用函数，理解参数传值及返回值。

## 核心概念

- 函数声明说明名称、返回类型和参数类型；调用前应存在可见声明。
- 函数定义包含函数体；声明与定义的类型必须一致。
- 普通参数按值传递，修改形参不会改变调用者的变量。
- `return` 返回结果并结束当前函数。
- 函数内定义的局部变量有自己的作用域。

## 示例说明

[max_of_two.c](max_of_two.c)：先声明函数，在 main 中调用，再定义比较逻辑

按[根目录运行说明](../README.md)单独编译本文件。示例使用固定数据，无需输入。

预期输出：

```text

```

## 常见错误

- 调用之前没有声明函数，或声明与定义不一致。
- 返回非 void 的函数有分支遗漏返回值。
- 以为改变普通整型参数会直接改变外部变量。
