# 05 结构体

[返回学习入口](../README.md) · [配套练习](../06-exercises/README.md)

## 学习目标

能用结构体组织相关数据，初始化对象并访问成员。

## 核心概念

- `struct Student` 将姓名、年龄和成绩组合成一个类型。
- 结构体定义末尾需要分号；声明对象时使用 `struct Student student`。
- 普通对象通过 `student.age` 访问成员；结构体指针通过 `pointer->age` 访问成员。
- `char name[20]` 为字符串预留 20 个字节，末尾的空字符也占一个字节。
- `%.1f` 将成绩以小数点后一位显示。

## 示例说明

[student.c](student.c)：初始化固定学生信息并逐项打印

按[根目录运行说明](../README.md)单独编译本文件。示例使用固定数据，无需输入。

预期输出：

```text
Name: Lin
Age: 18
Score: 92.5
```

## 常见错误

- 忘记结构体定义末尾的分号。
- 混淆对象的 `.` 与指针的 `->`。
- 试图在初始化后用赋值号给字符数组整体赋值。
- 读入姓名时没有限制长度，导致缓冲区越界。
