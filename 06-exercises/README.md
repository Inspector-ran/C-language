# 06 练习题

[返回学习入口](../README.md)

这些题目配合本仓库五个主题使用，初始不提供答案。每题使用独立的 `.c` 文件和 `main`，保存于本目录，例如 `01-sum-even.c`。编译方法见根 README。

输入通过标准输入提供，输出不要额外添加交互提示语，方便与样例比较。检查读取是否成功及题目规定的范围；输入不合法时返回非零退出码，无需约定错误消息。本套题目使用范围内的数值文本，不要求实现任意长度数字的解析器。

## 01 基础语法：偶数求和

建议文件名：`01-sum-even.c`。

输入一个整数 n（0 ≤ n ≤ 100），使用循环和分支计算 1 到 n（包含 n）之间所有偶数之和。

输入：

```text
10
```

输出：

```text
30
```

边界：n 为 0 或 1 时输出 0；n 为 2 时输出 2；n 为 100 时输出 2550。检查读取失败和超出范围的输入。

## 02 数组：读取并求和

建议文件名：`02-array-sum.c`。

第一项输入数组长度 n（1 ≤ n ≤ 20），随后输入 n 个整数，每个整数范围为 -100 到 100。先保存到固定容量为 20 的数组，再遍历求和并输出。

输入：

```text
5
1 2 3 4 5
```

输出：

```text
15
```

边界：单元素 -3 的和为 -3；{-2, 0, 5} 的和为 3；20 个 100 的和为 2000。先检查 n 再读取元素，避免访问越界。

## 03 函数：三个数的最大值

建议文件名：`03-max-of-three.c`。

输入三个整数（每个数范围为 -1000 到 1000），实现并调用 `int max_of_three(int a, int b, int c)`，输出最大值。

输入：

```text
3 7 5
```

输出：

```text
7
```

边界：{-3, -7, -5} 输出 -3；{4, 4, 4} 输出 4。不要把最大值初始值固定设为 0。

## 04 指针：原地逆序数组

建议文件名：`04-reverse-array.c`。

第一项输入长度 n（1 ≤ n ≤ 20），随后输入 n 个整数（每个数范围为 -100 到 100）。实现 `void reverse(int *values, size_t count)`，通过指针交换首尾元素，原地逆序，不创建第二个数组。输出用单个空格分隔，无末尾空格，最后换行。

输入：

```text
5
1 2 3 4 5
```

输出：

```text
5 4 3 2 1
```

边界：一个元素不变；{1, 2, 3, 4} 变为 {4, 3, 2, 1}；重复元素仍保留。使用 `size_t` 可包含 `<stddef.h>`，注意无符号数减法；函数应在 count < 2 时直接返回，避免计算 0 - 1。非空数组必须传入有效地址。

## 05 结构体：学生成绩汇总

建议文件名：`05-student-scores.c`。

使用结构体数组保存姓名与成绩。第一项输入学生数 n（1 ≤ n ≤ 10），随后每行输入姓名和成绩。姓名为 1～19 个 ASCII 英文字母、无空格；成绩为 0～100 的整数。

输出两行：平均分（保留一位小数）和最高分学生的姓名。最高分并列时选择输入顺序最早的一名。

输入：

```text
3
Lin 90
Chen 80
Wu 100
```

输出：

```text
Average: 90.0
Top: Wu
```

边界：只有 Lin 90 时，平均分为 90.0，最高分学生为 Lin；两人同分时选第一人；0 分与 100 分均有效。平均值使用浮点除法。姓名数组至少 20 字节，输入时限制宽度，并检查每项读取结果。
