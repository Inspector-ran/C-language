# 04 指针

[返回学习入口](../README.md) · [配套练习](../06-exercises/README.md)

## 学习目标

理解变量地址和解引用，能通过函数交换两个变量的值。

## 核心概念

- `&value` 取得变量地址，`int *pointer` 声明指向 int 的指针。
- `*pointer` 访问指针指向的对象，赋值可修改该对象。
- 指针参数本身也按值传递；传入地址后，函数可以修改地址对应的数据。
- 本例要求两个指针都指向有效、可写的 int 对象。不得传入空指针、未初始化指针或失效地址。
- 局部变量生命周期结束后，其地址不能再用于访问该变量。

## 示例说明

[swap.c](swap.c)：传入两个变量的地址，借助临时变量完成交换

按[根目录运行说明](../README.md)单独编译本文件。示例使用固定数据，无需输入。

预期输出：

```text
Before: 3, 7
After: 7, 3
```

## 常见错误

- 使用未初始化的指针或解引用空指针。
- 只交换指针变量本身，没有交换它们指向的值。
- 不保存原值，连续赋值后丢失其中一个数。
- 把 `first` 当作 `&first` 传给需要指针的函数。
