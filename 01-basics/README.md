# 01 基础语法

[返回学习入口](../README.md) · [配套练习](../06-exercises/README.md)

## 学习目标

理解程序入口，能使用变量、表达式、分支和循环完成简单计算。

## 核心概念

- 入口使用 `int main(void)`，`return 0;` 表示正常结束。
- `int` 保存整数，`double` 保存浮点数，`char` 保存字符；变量先初始化再使用，`const` 表示只读。
- `+`、`-`、`*`、`/` 是算术运算；整数相除舍去小数部分，`%` 用于整数求余。
- `=` 是赋值，`==` 是相等比较；`if/else` 根据条件选择分支。
- `for` 适合次数明确的循环；`while` 先检查条件再执行。注意循环是否会结束。
- `printf("%d\n", value)` 输出整数。读取整数可用 `scanf("%d", &value)`，只有返回值为 `1` 才能使用读入结果。
- `printf` 输出 `double` 用 `%f`，`scanf` 读取 `double` 用 `%lf`。输入练习先检查读取是否成功，再检查数值范围。

## 常见错误

- 把 `==` 写成 `=`，导致条件判断变成赋值。
- 忘记初始化累加器，或把 `<=` 写成 `<`，漏算最后一个数。
- 认为 `5 / 2` 等于 2.5；要得到浮点结果，可以使用 `5.0 / 2`。
- 读取失败后仍使用变量，或为 `scanf` 提供错误的格式及地址。
