# 02 数组

[返回学习入口](../README.md) · [配套练习](../06-exercises/README.md)

## 学习目标

能声明和遍历数组，理解下标范围，并对数组元素求和。

## 核心概念

- `int numbers[] = {1, 2, 3};` 定义连续存储的同类型元素。
- 长度为 `n` 的数组，下标范围是 `0` 到 `n - 1`。
- 在数组定义所在作用域，可用 `sizeof numbers / sizeof numbers[0]` 计算元素个数。
- `sizeof` 的结果类型为 `size_t`，可用来保存长度和下标。
- 数组作为函数参数时通常转换成指针，函数需要另外接收元素个数。

## 示例说明

[array_sum.c](array_sum.c)：遍历五个元素并累加，循环条件使用 index < count

按[根目录运行说明](../README.md)单独编译本文件。示例使用固定数据，无需输入。

预期输出：

```text
15
```

## 常见错误

- 使用 `index <= count` 访问越界元素。
- 把数组下标从 1 开始，漏掉第一个元素。
- 在接收数组参数的函数内使用 `sizeof` 推算原数组长度。
- 修改数组内容却没有同步检查预期输出。
